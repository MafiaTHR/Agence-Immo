# Dossier images

Placez ici vos propres images (captures d'écran en jeu, photos de biens, carte des zones...).

Exemples de fichiers attendus par le code fourni :
- `carte-zones.jpg` — utilisée sur la page /tarifs

Pour les images des biens, vous pouvez soit :
- référencer un chemin local ici (ex: `/images/mon-bien.jpg`) dans `src/data/properties.json`
- soit garder des URLs externes (photos de stock ou vos propres liens d'hébergement).
